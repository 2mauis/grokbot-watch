# 决策记录（2026-11-16）

1. **形态**：做官方 Grok Bot iPhone app 的轻量补充，不做独立的"胖" app。手表只负责回复和控制；iPhone 配套 app 负责登录、中转和语音。之前调研推荐的"独立 app + 直连 xAI API"方案作废，改为备选路线（architecture §8）。
2. **后端**：采用 Grok Bot 官方客户端的私有接口（参考 grok-wear），和官方 app 共用账号与记录。负责人明确接受风险，并限定为本人自用、非商业、不上架、只侧载。
3. **核心功能**：在手表上回复 Bot 消息，尤其是确认类问答，默认面向主 Bot；在手表上开关语音对话；麦克风在手表和手机之间智能选择。
4. **快速回答的优先级**：智能快速回复 → 自定义卡片 → 语音输入（ASR，最后的兜底）。
5. **仓库**：私有仓库 `grokbot-watch`，MIT 许可；按 workflow-template 2.2.2 起步；本轮只写规格和设计评审，不写实现，不加 CI。
6. **降级**：手表有网而手机不在身边时，走手表 HTTPS 直连（手表独立登录，token 不跨设备传送）。
