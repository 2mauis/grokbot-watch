## 2. Grok Bot 对外接口

- 没有官方公开的聊天 API。Cursor 论坛的官方答复说，目前没有可以列 Bot、发消息、读回复的公开 API/SDK（[论坛帖](https://forum.cursor.com/t/grok-bot-official-api-to-create-bots-and-send-receive-chat-for-companion-uis/170985/6)）。
- 官方入口只有 routine webhook，只能触发，读不到回复（[Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations)）。
- 官方客户端支持 iOS 18+ 和 Android，没有手表 app（[Grok Bot for Mobile](https://docs.x.ai/grok-bot/mobile)）。
- 私有接口可能不符合 [xAI Acceptable Use Policy](https://x.ai/legal/acceptable-use-policy)（限制以 bot 方式访问和逆向服务）。负责人已知悉并接受，限定为个人自用。

## 3. watchOS 能力边界（Apple 官方）

| 能力 | 结论 | 链接 |
|---|---|---|
| HTTPS | 所有 app 都能用，包括 `bytes(for:)` 流式读取（watchOS 8+） | [TN3135](https://developer.apple.com/documentation/technotes/tn3135-low-level-networking-on-watchos)、[bytes(for:)](https://developer.apple.com/documentation/foundation/urlsession/bytes(for:delegate:)) |
| WebSocket / Network framework | 只在音频流 app 实际播放期间或 CallKit 通话中可用；模拟器总是放行，必须真机测 | [TN3135](https://developer.apple.com/documentation/technotes/tn3135-low-level-networking-on-watchos) |
| 听写 | 系统文本输入（含听写，可以带 app 提供的候选） | [presentTextInputController](https://developer.apple.com/documentation/watchkit/wkinterfacecontroller/presenttextinputcontroller(withsuggestions:allowedinputmode:completion:))、[TextFieldLink](https://developer.apple.com/documentation/swiftui/textfieldlink) |
| Speech 框架 | watchOS 不可用（`SFSpeechRecognizer`、`SpeechAnalyzer` 的平台列表都没有 watchOS） | [SFSpeechRecognizer](https://developer.apple.com/documentation/speech/sfspeechrecognizer)、[SpeechAnalyzer](https://developer.apple.com/documentation/speech/speechanalyzer) |
| 录音和播放 | `AVAudioEngine`（watchOS 2+）、`AVAudioRecorder`（watchOS 4+）、`AVSpeechSynthesizer`（watchOS 2+） | [AVAudioEngine](https://developer.apple.com/documentation/avfaudio/avaudioengine)、[AVAudioRecorder](https://developer.apple.com/documentation/avfaudio/avaudiorecorder)、[AVSpeechSynthesizer](https://developer.apple.com/documentation/avfaudio/avspeechsynthesizer) |
| 后台 | 后台模式只有 workout、self-care、mindfulness、physical-therapy、alarm、underwater-depth；AI 助手不能常驻 | [WKBackgroundModes](https://developer.apple.com/documentation/bundleresources/information-property-list/wkbackgroundmodes)、[WKExtendedRuntimeSession](https://developer.apple.com/documentation/watchkit/wkextendedruntimesession) |
| WatchConnectivity | 手表活跃时 `sendMessage` 能在后台唤醒 iOS app，反之不行；application context 保留最新状态 | [sendMessage](https://developer.apple.com/documentation/watchconnectivity/wcsession/sendmessage(_:replyhandler:errorhandler:))、[isReachable](https://developer.apple.com/documentation/watchconnectivity/wcsession/isreachable) |
| iPhone 后台录音 | 从后台启动录音可能失败（`cannotStartRecording`），需要 S-3 验证 | [cannotStartRecording](https://developer.apple.com/documentation/coreaudiotypes/avaudiosession/errorcode/cannotstartrecording) |
| 小组件 / complication | WidgetKit（watchOS 9+），可以用作 complication 和 Smart Stack 卡片 | [Accessory widgets](https://developer.apple.com/documentation/widgetkit/creating-accessory-widgets-and-watch-complications) |
| Siri | App Intents（watchOS 9+） | [App Intents](https://developer.apple.com/documentation/appintents) |
| 交互 | 交互时间短；complication、通知、Siri 的使用频率往往比 app 本身高 | [HIG: Designing for watchOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-watchos) |

## 4. 智能快速回复相关的 Apple API

- 信息 app 那种上下文智能回复，没有对第三方开放的 API。WatchKit 只支持在系统输入界面里展示 **app 自己提供**的候选（`presentTextInputController(withSuggestions:)`、`…WithSuggestions(forLanguage:)`）。
- [Foundation Models](https://developer.apple.com/documentation/foundationmodels)：iOS 26+ 可用；框架从 watchOS 27 起列入，但设备端 [`SystemLanguageModel`](https://developer.apple.com/documentation/foundationmodels/systemlanguagemodel) 不支持 watchOS；[`PrivateCloudComputeLanguageModel`](https://developer.apple.com/documentation/foundationmodels/privatecloudcomputelanguagemodel)（watchOS 27+）需要满足资格条件并申请受管 entitlement。
- 因此由 iPhone 端生成候选（先用设备端模型，再退到规则模板），推给手表。

## 5. xAI 官方接口（备选路线和语音协议参考）

- Responses / Chat Completions 支持 SSE 流式：[Overview](https://docs.x.ai/docs/overview)、[Streaming](https://docs.x.ai/docs/guides/streaming-response)
- Realtime 语音：`wss://api.x.ai/v1/realtime`，客户端用 ephemeral token（`POST /v1/realtime/client_secrets`），通过 `xai-client-secret.` 子协议认证：[Ephemeral Tokens](https://docs.x.ai/developers/model-capabilities/audio/ephemeral-tokens)、[Voice API 参考](https://docs.x.ai/developers/rest-api-reference/inference/voice)
- REST 形式的 `/v1/stt` 和 `/v1/tts`：同上 Voice API 参考
